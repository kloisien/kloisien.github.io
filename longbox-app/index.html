Ownership and reading are tracked separately, so On the shelf, unread is the number that matters — what you already paid for and have not got to yet. Those rows carry a gold edge in the table.
Progress saves to this browser only. Export gives you a JSON backup you can re-import anywhere.
The reliable route for covers: run gcd_isbn.py against a Grand Comics Database export to get exact ISBNs, Import details file, then Fill covers from ISBNs. An ISBN is an exact key, so nothing gets matched to the wrong book.
Import details file loads covers, descriptions, ISBNs and page counts in bulk from a details.json produced by the enrich.py script (which runs on your own machine, where nothing blocks it).
Per book, open it and use Find cover from ISBN — the ISBN is on the Comic Geeks page under UPC/ISBN. Only an image that actually loads is kept, and if nothing is found it tells you why.
Fetch covers automatically queries Google Books, falling back to Open Library, matching on trade paperback titles. Filter to an era first if you only want part of the list. Anything it cannot match stays a placeholder — tap it in Covers view to paste a URL by hand. Unmatched titles are listed in the browser console.
Issue ranges tagged VERIFY are estimates — confirm on Comic Vine or the Grand Comics Database before buying.
